PowerDebug 1.1.9 Release Notes

2012.09.11
There is now a Breakpoints tab in addition to the Triggers tab.
The Triggers tab highlights if there are watched variables.
The filter textbox is now in the toolbar alongside the trace delay.
The trace delay rescales properly with the stack resizing.
Double-clicking a breakpoint in the list removes the breakpoint.
Right-clicking a breakpoint edits that line in the script of that object.
Global variables can now be watched variables.
Resizing the stack hides/uncovers tabs as needed.

PowerDebug 1.1.8 Release Notes

2012.07.27
Got Trace mode working again. I guess nobody was using it.
There's a code coverage tool, of a sort:
  Place a breakpoint early in the code
  Set the trace delay to 0 for best results
  When the debugger starts, click Trace
    (Escape stops trace mode)
  After tracing, select the Code Coverage tab
    This will show you what lines of code have been executed.
